Lesson 1: Proper HTML Structure

One of the most important aspects of web development is understanding the proper structure of an HTML
document. Below is a basic template that outlines the essential elements needed for a well-formed HTML page:

<!DOCTYPE html>
<html lang="en">
<head>
 <meta charset="UTF-8">
 <meta name="viewport" content="width=device-width, initial-scale=1.0">
 <title>The Review Website</title>
 <link rel="(Put relationship here)" href="(Put CSS file path here)">
</head>
<body>



 (Content goes here)



<script src="(Put JavaScript file path here)"></script>
</body>
</html>

Lesson 2: Semantic Tags and Non-Semantic Tags

Semantic Tags are HTML tags that have a specific meaning and purpose, while Non-Semantic Tags do not convey any particular meaning. Understanding the difference between these two types of tags is crucial for creating well-structured and accessible web pages.
